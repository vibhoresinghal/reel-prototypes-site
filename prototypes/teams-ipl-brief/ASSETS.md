# Asset sources

- Interface icons: original Microsoft Fluent System Icons SVGs, npm package `@fluentui/svg-icons` version 1.1.345. Embedded paths preserved; fill inherits the interface colour. MIT license in FLUENT-ICONS-LICENSE.txt. https://github.com/microsoft/fluentui-system-icons
- Teams brand mark: https://cdn.worldvectorlogo.com/logos/microsoft-teams-1.svg (same artwork as earlier Teams cards).
- Anoop's portrait: user-supplied image, copied without modifications.
- Fallback Inter font files: @fontsource/inter; OFL in FONT-LICENSE.txt. Segoe UI is preferred where installed.
- All conversation text is staged copy for recording; no chat service is connected.
